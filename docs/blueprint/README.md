# Build Blueprint

`Dual_Axis_Solar_Tracker_Final_Build_Blueprint_UPDATED_MDF.pdf` (23 Sep 2026) is the
reference for dimensions, cutting lists, pin map and tracking settings: four levels
(MDF base, MDF azimuth deck, acrylic elevation frame, acrylic panel assembly), 20 mm
MDF, servo pins D11/D12/D5/D6, and the settings used in `solar_tracker_main/`.

`design-concept.png` is the original concept drawing (12 mm plywood, earlier servo pins). The layout is unchanged; the PDF above is current for materials and pins.
